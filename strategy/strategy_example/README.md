# strategy_example

12-1 动量示例策略，用来演示策略文件夹的标准格式，不作为研究结论。

| 项目 | 内容 |
| --- | --- |
| 研究问题 | 过去一年（跳过最近一个月）涨得多的大盘股，下一个月是否继续跑赢 |
| 假设 | 动量效应：近一年的赢家短期内继续跑赢；跳过最近一个月以避开短期反转 |
| 资产集 | 30 只美股大盘股（config.yaml 的 universe） |
| 数据 | Sharadar SEP，close_adj（拆股和分红调整后的收盘价） |
| 信号 | t-21 日收盘价相对 t-252 日收盘价的涨幅 |
| 选股与权重 | 动量前 10 名，等权各 9.5%，合计 95%，只做多 |
| 调仓 | 每月最后一个交易日出信号，下一个交易日收盘成交 |
| Paper trading | 账户 STRATEGY_EXAMPLE，资金 100,000 美元，enabled: false |
| 样本划分 | IS 2019-02-04 至 2022-12-30；Embargo 21 个交易日（不评价）；OOS 2023-02-02 至信号日，只做报告 |
| 最新报告 | records/2026-11-02-dryrun.pdf（信号日 2026-10-30） |
| 回测 IS（无成本） | 年化收益 23.6%，年化波动 26.2%，Sharpe 0.94，最大回撤 -30.2%，年换手 2.06；等权基准 Sharpe 0.92 |
| 回测 OOS（无成本） | 年化收益 32.4%，年化波动 20.6%，Sharpe 1.47，最大回撤 -25.6%，年换手 2.37；等权基准 Sharpe 1.78 |
| 回测全样本（2019-02 至 2026-10，无成本） | 年化收益 26.8%，年化波动 23.5%，Sharpe 1.13，最大回撤 -30.2%；等权基准 Sharpe 1.24 |
| 结论 | IS 中动量组合与等权基准的 Sharpe 基本持平（0.94 对 0.92），收益略高但波动更大；OOS 收益更高，但 Sharpe 低于基准（1.47 对 1.78）、回撤更深。经风险调整后不优于简单等权持有，不建议据此上线 |
| 已知局限 | 资产集是当前名单，回测有幸存者偏差；Alpaca paper 账户不发分红，paper 收益略低于回测 |
