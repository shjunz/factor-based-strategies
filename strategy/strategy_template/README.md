# strategy_template

策略卡片：一句话说明这个策略做什么。每次干跑后，用最新的 PDF 报告更新“最新报告”、三行“回测”和“结论”；参数只按 IS 选，OOS 只做报告。

| 项目 | 内容 |
| --- | --- |
| 研究问题 | 待填写 |
| 假设 | 待填写：背后的经济逻辑 |
| 资产集 | 待填写：config.yaml 的 universe 是什么股票 |
| 数据 | Sharadar SEP，待填写 data.field |
| 信号 | 待填写：公式和窗口 |
| 选股与权重 | 待填写：选几只、怎么分配权重、是否做空 |
| 调仓 | 待填写：rebalance 是 D、W 还是 M |
| Paper trading | 待填写：账户名、资金、enabled |
| 样本划分 | 待填写：config.yaml split 的 IS 区间、Embargo 长度、OOS 区间 |
| 最新报告 | 待填写：records/ 下最新的 PDF |
| 回测 IS（无成本） | 待填写：年化收益、波动、Sharpe、最大回撤、年换手，与等权基准对比 |
| 回测 OOS（无成本） | 待填写：同上，只做报告，不据此改参数 |
| 回测全样本（无成本） | 待填写：区间和同上指标 |
| 结论 | 待填写：先看 IS，再看 OOS 是否一致 |
| 已知局限 | 待填写 |
