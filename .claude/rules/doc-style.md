# Document Style Guide

适用于所有中文文档。

## 1. 内容

- 只写已经在用或已经决定的内容，不为了"完整"而补。保留分类结构，让以后的新内容能直接放进现有分类。可选的方法保持可选。
- 内容在原地写清楚。引用其他章节时只能指向前面的章节，不能指向后面的章节。

## 2. 结构

- 一级章节（如 M1）用"本节按……分为 N 部分："列出各部分；二级章节不列出自己的下级章节。
- 二级章节（如 M1.1）以定义开头，写成"X 指……"。
- 三级章节（如 M1.1.1）像说明书一样，用带主语的完整句子来写，不用"X 指……"。

## 3. 用词

- 并列的条目和单元格用同一种句式、同样的详细程度，不要只给其中一条加条件。
- 需要解释的术语写成"X 是……，列名为 `col`"。
- 按资产类别区分的规则写成"各资产类别的……如下："，后面接加粗的资产类别条目。
- 映射表用一句话说明："我们创建一张映射表 `path`，用来把 A 转换成 B，每个 … 占一行。"

## 4. 表格

- 单元格只放简短、统一的查询值，比如代码、列名、一句话含义。需要写整句的，改成加粗标签的列表。不放示例列，也不放指向后面章节的链接。
- 中文列在前，代码或符号列在后，例如 `信息 | 字段`。
- 数据卡片的每格尽量短，同一列的取值要统一，例如"修订/历史版本"只填"是/否/待确认"。

## 5. 编辑修改

- 一次只改一张表或一节，等确认后再继续。要删除内容或替换说法，单独提出来问。
- 章节名或编号有变化时，直接同步更新文档开头的目录表（如 M0）。
